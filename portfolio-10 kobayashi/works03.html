小林建設 コーポレートサイト（自主制作）

Web制作の学習を始めて最初に制作したWebサイトです。HTMLとCSSの基礎を学びながら、構成・ロゴ制作からデザイン、コーディングまで一貫して形にすることを目標に取り組みました。

URL

https://あなたのアカウント名.github.io/リポジトリ名/

担当

企画・情報設計 / ロゴ制作 / UIデザイン / コーディング（HTML5 / CSS3）
使用ツール：Figma / Visual Studio Code / Adobe Illustrator

サイトの目的

地域密着型の建設会社「小林建設株式会社」のコーポレートサイトです。施工実績や会社のこだわりを分かりやすく伝え、注文住宅やリノベーションを検討しているお客様からの信頼獲得・お問い合わせに繋げることを目的に制作しました。

ターゲット

・30代〜40代のファミリー層：価格の安さよりも、建物の構造・安全性や自由設計など「長く愛着を持って暮らせる家づくり」を求める層。

デザインについて

建築会社らしい誠実さと洗練された雰囲気が伝わるよう、白ベースに広い余白と明朝体・ダークグレーを組み合わせています。企業の顔となるロゴもIllustratorで一から制作し、サイト全体の雰囲気と統一しました。また、初めて見た人でも迷わず情報を追えるよう、関連する写真とテキストの距離を近づけ、セクションごとの余白をしっかり分けることで見やすさを意識しています。

コーディングについて

後から施工事例やページが増えても管理しやすいよう、HTMLのタグの意味（article など）を正しく使い分けて構造を整理しました。どの画面幅で見てもレイアウトが崩れないよう、余白やカード並びのバランスを細かく調整しています。
