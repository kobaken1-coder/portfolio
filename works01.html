TRIGGER 1st ONEMAN LIVE「LOCK_ON」特設サイト

3人組VTuberグループの初ワンマンライブ特設プロモーションサイトです。IPの世界観に没入させるビジュアル演出と、情報解禁直後のファンが迷わずチケット申込・限定グッズ購入へ進めるUI導線の両立を目指して制作しました。

URL

https://adjustacademy.com/0117/d260710-700117/site03/index.html

担当

企画・情報設計 / ロゴ・UIデザイン（Figma / Illustrator） / コーディング（HTML5 / CSS3 / JavaScript / jQuery）

サイトの目的

ライブ情報解禁時のファンの熱量を逃さず受け止め、チケット申込および限定グッズ購入（CV）へのアクションを最大化すること。

ターゲット

10代後半〜20代後半のVTuber・音楽ライブファン層（SNS・配信からの流入を想定し、スマートフォン 90% / PC 10% で設計）

デザインについて

架空の3人組VTuberグループ「TRIGGER」の初ワンマンライブ告知サイトです。サイバーパンクの世界観を大切に表現しつつ、見ている人がストレスなく操作できるように意識しました。TRIGGERの魅力を伝えながら、チケット購入までの流れを分かりやすく整理し、迷わず購入へ進めるようにすることを目的に制作しています。

コーディングについて

背景を黒色、文字色を白色に設定してコントラストをはっきりさせ、フォントもサイバー感のある書体を選ぶことで画面全体の雰囲気を統一しました。 ファーストビューの背景にはRGBの色ズレや横スライスのグリッチ演出を取り入れ、サイバーパンク感を表現しています。ずっとノイズが動き続けると目が疲れて視認性が下がるため、一瞬だけノイズが走るように調整し、演出の派手さと情報の見やすさのバランスを意識しました。
