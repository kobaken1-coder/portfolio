TRIGGER 1st ONEMAN LIVE「LOCK_ON」特設サイト

3人組VTuberグループの初ワンマンライブ特設プロモーションサイトです。IPの世界観に没入させるビジュアル演出と、情報解禁直後のファンが迷わずチケット申込・限定グッズ購入へ進めるUI導線の両立を目指して制作しました。

URL

https://あなたのアカウント名.github.io/リポジトリ名/

担当

企画・情報設計 / ロゴ・UIデザイン（Figma / Illustrator） / コーディング（HTML5 / CSS3 / JavaScript / jQuery）

サイトの目的

ライブ情報解禁時のファンの熱量を逃さず受け止め、チケット申込および限定グッズ購入（CV）へのアクションを最大化すること。

ターゲット

10代後半〜20代後半のVTuber・音楽ライブファン層（SNS・配信からの流入を想定し、スマートフォン 90% / PC 10% で設計）

デザインについて

SNSの告知ポストやYouTube配信からのスマートフォン流入（全体の9割）を前提に、ファーストビューでライブの熱量を伝えつつ、片手操作でもストレスなくチケット詳細や購入ボタンへたどり着ける縦導線を設計しました。
ダークトーンを基調にネオンカラーをアクセントとして効かせ、タイトルロゴの「LOCK_ON（照準）」モチーフと連動したサイバーパンクの世界観をサイト全体で統一しています。また、ライブ注意事項などの情報量が多いセクションも、スマホ画面で圧迫感が出ないよう余白とジャンプ率を細かく調整しました。

コーディングについて

エンタメ案件特有の「急な情報追加・修正」が発生してもレイアウトが崩れないようCSSの詳細度を整理し、!important を一切使わない保守性の高い設計を徹底しました。
また、告知直後のスマホ実機アクセスでも表示速度を落とさないよう、重たい動画ファイルは使わずCSSの擬似要素とブレンドモードでグリッチ風の演出を実装。さらに、HTML標準の details / summary タグを活用したアコーディオンや不要な処理を削ぎ落とす「引き算の設計」により、演出のクオリティと軽量・高速な動作を両立させています。
